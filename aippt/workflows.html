AI 制作 PPT 核心极速提效工作流

本页收录了课程中最具实操价值的“降维打击”式工作流，配套现成的 Prompt 模板，拿来即用。

一、10分钟极速建片工作流（无痛冷启动）

当老板扔给你一份几页纸的长篇演讲稿，要求你 10 分钟后汇报，你可以直接运行这套工作流：

1 结构提炼

将整篇文字复制给 ChatGPT，让其整理成标准的 1-2 级标题目录结构大纲。

2 Markdown 转化

使用特定 Prompt 指令，命令 ChatGPT 将大纲重新排版为纯 Markdown 语法的代码块输出。

3 导入 MindShow

复制 Markdown 代码块，粘贴进 MindShow 网站的导入框中，一键预览并导出为 PPT 格式。

📋 关键步骤一：Markdown 转换 Prompt 指令卡

在 ChatGPT 中大纲梳理好后，输入以下指令：

ChatGPT Prompt
请根据刚刚确定的 PPT 大纲内容，使用 Markdown 语言编写成代码块（Code Block）输出。每一页的 PPT 标题请用 # 表示，二级标题或要点请用 ## 或无序列表 - 表示。不要有任何多余的解释，直接输出代码块。
🎨 关键步骤二：AI 辅助配图占位符 Prompt 指令卡

如果你希望在极速大纲生成时直接带上精准的图片，可以输入这串特殊的 Markdown 图片占位符提示词：

ChatGPT Prompt (Unsplash API 桥接)
接下来发照片时，请使用 Markdown 语言格式，不要包含斜线，不要使用任何代码块包裹，统一使用 unsplash API 格式：https://source.unsplash.com/1080x720/?<英文关键词>。每一页大纲请提取一个与之最贴切的英文关键词替换，如果理解了，请直接回复 OK。

二、高定风格复刻与 AI 底图生成流

如果客户发给你一张很有设计感的 PPT 图片，要求发布会也做这个风格，但里面的元素和文字需要完全更换，可采用此流：

🖼️ Midjourney 双向复刻与生成步骤
  1. 分析与拆解风格：打开 Midjourney 的对话框，输入 /describe 指令，上传客户的参考图片。
  2. 提取关键词：Midjourney 会自动返还 4 组对该图色彩、构图、风格（如“蒸汽波风格”、“极简主义”、“磨砂玻璃效果”）的英文描述关键词。
  3. 图像复刻与定制：使用 /imagine 指令。先将客户原图拖入对话框（作为参考图链接），然后复制刚才最贴切的关键词，并在其后加上关键的控制参数：
    <参考图 URL> a sleek vector design, a futuristic office environment, tech purple and orange colors --chaos 1 --iw 2 --ar 16:9
    • --chaos 1：控制图片的随机性（0-100），数字越小，随机度越低，生成的一组图风格越统一。
    • --iw 2：控制参考图权重（0-5），数值越大，生成的图片和客户原图越像（默认为 0.25）。
    • --ar 16:9：指定宽屏屏幕比例，做 PPT 必带此参数。

三、动态微特效背景生成流

想要让你的 PPT 从普通工业品一跃成为高逼格科技现场，可以尝试生成动态背景：

  1. 在 Midjourney 里生成好你满意的 16:9 精美底图。
  2. 打开 Kaiber.ai 网站。上传该底图。
  3. 在动效 Prompt 文本框中输入你希望产生的微动效描述（例如：星星微闪、光影浮动、背景粒子缓缓升起，天空由黄变蓝）。
  4. 风格选择“Cinema”（电影画质），运动时间设置为 4 秒，导出 MP4 视频。
  5. PPT 内嵌入：打开 PowerPoint，将导出的 4 秒 MP4 拖拽进幻灯片底层，在“视频-播放”选项卡中，将开始方式设为“自动”，并勾选“循环播放”，即可得到一个有呼吸感的动态幻灯片背景。

四、数据逻辑与金句提炼流

如何快速在 PPT 里突出重点，避免让老板觉得“内容多但没重点”？

📊 动态图表与同步更新

  • Power BI 实时联动：若数据在 Excel 频繁更改，可在 Power BI 中把数据生成动态图表，并将链接嵌入 PPT。在 PPT 中点击“更新链接”，数据图表自动同步更新，省去重新做图表的麻烦。
  • 镝数图表动态导出：利用镝数图表生成极其好看的动态数据图表，导出为 GIF 后拖入 PPT；或导出透明底 PNG，无痛适配任何背景色的 PPT 模版。

✍️ ChatGPT 风格化金句提炼

不要直接让 ChatGPT 写金句。最好的三步提问法：

  1. 第一步（先给身份）：“现在我希望你是鲁迅（或老舍/知名广告人）。如果你理解了，请回复 OK。”
  2. 第二步（确保风格理解）：“请简要说一下你的语言写作特征并举个例子。”
  3. 第三步（生成金句）：“请根据以下文案，写出 3 句强调新消费市场巨大潜力的鲁迅文风金句，字数控制在 25 字以内，要简短有力。”
